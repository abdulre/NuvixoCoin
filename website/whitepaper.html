Section 01

Abstract

NuvixoCoin (NXC) is a decentralized Proof-of-Stake blockchain platform designed to provide secure, efficient, and feature-rich digital value transfer. Built on the battle-tested NXT codebase originally developed in 2013, NuvixoCoin inherits over a decade of blockchain engineering while introducing a fresh identity, modern security hardening, and a clearly defined economic model.

The platform operates with a fixed total supply of 1,000,000,000 NXC — no inflation, no mining, no pre-sale surprises. Block generation is powered entirely by stakeholders who earn transaction fees as their reward, creating a self-sustaining economic loop that incentivises long-term participation over short-term speculation.

NuvixoCoin is not just a coin. It is a complete blockchain platform with a built-in asset exchange, monetary system, digital goods store, voting mechanism, encrypted messaging, privacy shuffling, and a full developer API — all available from day one.

Section 02

Introduction

2.1 Problem Statement

The modern cryptocurrency landscape is dominated by two extremes: heavyweight Proof-of-Work chains that consume enormous energy, and complex smart-contract platforms with steep learning curves and unpredictable gas fees. Neither serves the everyday user who simply wants a fast, secure, and affordable way to transfer value and build applications.

Furthermore, most newer coins are built on rushed forks with undisclosed vulnerabilities, empty treasuries, and no working product — launched purely for speculative gain.

2.2 The NuvixoCoin Approach

NuvixoCoin takes a different path. Rather than reinventing the blockchain from scratch, it builds on the NXT protocol — one of the first pure Proof-of-Stake blockchains, operational since 2013 with a proven track record of security and stability. This approach provides:

  • A decade of battle-tested consensus code with known behaviour
  • A rich feature set available immediately at launch
  • A clean, auditable codebase that any developer can inspect
  • A fresh economic model with full transparency from genesis block

2.3 Vision

NuvixoCoin aims to become a reliable, community-driven blockchain platform that prioritises substance over hype. Every NXC in existence is accounted for from block zero. Every feature works out of the box. Every transaction is final and verifiable by anyone.

Section 03

Technical Architecture

3.1 Consensus: Proof of Stake

NuvixoCoin uses a pure Proof-of-Stake consensus mechanism. Block generators — called forgers — are selected probabilistically based on their effective stake, defined as their confirmed balance after 1,440 block confirmations (approximately 24 hours).

The probability that a forger generates the next block is proportional to their effective stake divided by the total effective stake of all active forgers. This ensures that larger stakeholders contribute more to network security while smaller holders can still participate meaningfully.

P(forge) = effective_stake_account / total_effective_stake_network

There are no block rewards in the traditional sense. Forgers receive the sum of all transaction fees included in the blocks they generate. This creates zero inflation while still incentivising participation.

3.2 Cryptography

NuvixoCoin uses industry-standard cryptographic primitives throughout:

  • Key generation: Curve25519 elliptic curve Diffie-Hellman for account keypairs
  • Transaction signing: Ed25519 digital signatures
  • Hashing: SHA-256 for block and transaction hashing
  • Encrypted messaging: Curve25519 + AES-256 for end-to-end encrypted messages
  • Passphrase hardening: SHA-256 derived private keys (Scrypt available for enhanced security)

The cryptographic library used is Bouncy Castle (bcprov-jdk18on), the industry standard for Java cryptography.

3.3 Database & Storage

The blockchain state is stored in an H2 embedded relational database. This design choice provides ACID-compliant transactions, full SQL query capabilities for the API layer, and reliable data integrity without requiring an external database server.

The database schema uses a versioned migration system — each schema change is tracked and applied automatically on upgrade, ensuring safe forward migrations without data loss.

Full-text search is powered by Apache Lucene, enabling fast queries over aliases, asset names, goods listings, and tagged data.

3.4 Networking

Nodes communicate over a JSON-based peer-to-peer protocol on port 27874. The network layer supports both HTTP and WebSocket connections between peers, with configurable rate limiting (DoS protection at 30 requests/second per peer), connection pooling, and automatic peer discovery via a well-known peer bootstrap list.

The API server runs on port 7876 using Jetty, exposing a comprehensive JSON API for wallet operations, blockchain queries, and node administration.

Section 04

Tokenomics

4.1 Supply

The total supply of NuvixoCoin is fixed at exactly 1,000,000,000 NXC (one billion). This supply was established at genesis and is mathematically enforced by the protocol — no new coins can ever be created.

Each NXC is divisible to 8 decimal places, giving a smallest unit of 0.00000001 NXC (one NQT — NuvixoCoin Quantum Token). This provides sufficient precision for micro-transactions and fee calculations for many decades.

MAX_BALANCE_NQT = 1,000,000,000 × 100,000,000 = 100,000,000,000,000,000 NQT

4.2 Distribution

The entire supply was allocated at the genesis block on 1 January 2025. Every NXC in existence is publicly visible on the blockchain from block zero.

4.3 Forging Rewards

There are no block subsidies. Forgers earn only the transaction fees from the blocks they generate. As network usage grows, fee revenue for active forgers grows proportionally. This model ensures that the coin supply remains fixed while still providing meaningful economic incentive for network participants.

The minimum balance required to participate in forging is 1,000 NXC. Any account holding this balance and running a node can start forging immediately — no registration, no staking lockup, no slashing risk.

Section 06

Security

6.1 Protocol Security

The NXT Proof-of-Stake protocol has been running in production since 2013. Its consensus mechanism has been formally reviewed and the codebase has been audited by multiple independent researchers over its operational lifetime.

NuvixoCoin inherits this protocol unchanged, including its resistance to nothing-at-stake attacks (via forging delay), long-range attacks (via checkpointing), and Sybil attacks (via stake-weighted selection).

6.2 Network Security

  • DoS protection on the peer server — rate limited to 30 requests per second per peer
  • API server bound to localhost by default — requires explicit configuration to expose publicly
  • Admin API protected by password — node refuses to start with empty password on public interfaces
  • CORS disabled by default — only explicitly whitelisted origins allowed
  • Peer connections enforce minimum version — old nodes are rejected
  • All inter-node communication uses signed JSON — forged messages are rejected

6.3 Dependency Security

NuvixoCoin's build system includes the OWASP Dependency Check tool. Every release is scanned for known CVEs in all third-party libraries before publication. The project targets Java 17 LTS which receives security updates through 2029.

6.4 Responsible Disclosure

Security vulnerabilities should be reported privately to security@nuvixocoin.com. We follow a 90-day responsible disclosure policy and acknowledge all valid reports.
